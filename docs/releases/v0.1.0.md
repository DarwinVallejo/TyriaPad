First release of TyriaPad: controller support for Guild Wars 2 with a ConsolePort-style glyph overlay, built for the ROG Ally X. It installs no drivers, doesn't create a virtual controller or hide the real one, and doesn't read the game's memory.

> TyriaPad is a fan project and is not affiliated with ArenaNet or NCSOFT.

## Installation

1. Download `TyriaPad-v0.1.0-win-x64.zip` and extract it to a folder of your own (for example `Documents\TyriaPad`). No need to install .NET.
2. Open `TyriaPad.exe`. It shows up in the system tray; double-click the icon to open the settings.
3. In GW2: set the game to **Windowed Fullscreen** and bind a key to "Toggle Action Camera" (TyriaPad uses `,` by default).
4. On the Ally X: Armoury Crate SE in **Gamepad** mode and Steam Input turned off for GW2. Details in `docs/armoury-crate-se.md`, in the repository.

Windows may show a SmartScreen warning ("Windows protected your PC") because the executable isn't signed: "More info" → "Run anyway".

To uninstall, turn off "Start with Windows" if you turned it on and delete the folder.

## What's included

- **Full controller mapping** with layers (LB, LT, LT+RT), gestures (tap, hold, double tap) and contexts (combat, cursor, mount). The default profile is Blaggletoad's v5.0 layout.
- **Two camera modes**: Action Camera (the right stick turns the camera) and cursor (the stick moves the cursor for menus and inventory). Holding Menu switches between them; the mode also follows the Windows cursor.
- **Overlay** on the skill bar showing the button that triggers each skill, which changes while you hold LB or LT, plus the radial menus (mounts, masteries, windows) and a mode indicator.
- **Reads the keybinds GW2 exports** to place the glyphs where they belong and warn about keys with no action.
- **Works on the Windows desktop and in the Xbox full screen experience**, with no drivers: if Windows doesn't provide the controller through XInput, TyriaPad reads it through Raw Input.
- **Ally X M1/M2** via HID (M1 = mount and mount radial).
- **Settings window**: sensitivity and deadzones, overlay, a visual button and layer editor on a drawing of the controller, and a radial editor. Changes apply on save, without restarting.
- **Start with Windows** (a shortcut in the Startup folder, no registry): with GW2 closed it stays idle. It can also close by itself when GW2 closes.

## Known limitations

- In the Xbox full screen experience (Xbox mode) the controller is read through Raw Input, because Windows doesn't give XInput to background apps. There LT and RT share an axis: pressed together they cancel out, so the LT+RT layer doesn't activate (F5–F8 are still on LT + D-pad). The Windows desktop doesn't have this limitation.
- GW2 has to be windowed or in Windowed Fullscreen for the overlay to show.
- M1 and M2 send the same code through the path TyriaPad reads, so they do the same thing. They must stay unassigned in Armoury Crate SE.
- The overlay doesn't know which skills you have equipped or their cooldowns (that would require reading the game's memory).
